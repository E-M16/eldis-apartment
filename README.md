# Eldi's Apartment website

This version keeps the existing design and functionality while separating custom code.

## Structure

- `index.html` — page markup and SEO structured data
- `css/style.css` — custom styles
- `js/booking.js` — smart dates, Turnstile, and contact form submission

## Deployment

Upload the complete folder contents to the repository root. Keep the `css` and `js` directories exactly as provided, then commit the changes. Cloudflare Pages will redeploy automatically.
